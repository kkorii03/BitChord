작업: 커버 영상이 다운로드된 원곡으로 바뀌는 버그 수정 (BitChord 안드로이드, Kotlin)

증상(폰 로그로 확인): 사용자가 원곡을 다운로드해 둔 경우, 커버 영상(다른 가수가 부른 영상)을 틀면 로그에
'song version: <커버 videoId> -> <원곡 videoId> via download' 가 찍히고 원곡이 재생된다.
예: Dance Hall 커버 etyHAg3sADA, 야화 커버 vqskFsBLeUs. 커버는 커버 자체로 재생돼야 한다.

할 일:
1. grep/Select-String 으로 'via download' 로그를 찍는 코드를 찾고(rg 는 없음, 저장소 전체 목록 출력 금지), 다운로드 사본으로 교체하는 조건을 확인.
2. 다운로드 교체는 '같은 곡의 노래 버전'일 때만 허용. 원본이 커버(커버 판정 함수가 이미 있으면 그것을 재사용, 예: TrackMatcher/커버 제외 로직)이거나 업로더·가수가 다르면 교체하지 않는다.
   MV → 노래 버전(ATV) 교체 원칙은 그대로 유지(원곡 MV 를 틀었을 때 다운로드된 원곡 노래 버전으로 바뀌는 것은 정상).
3. 판정 함수 단위 테스트 추가(커버→원곡 다운로드: 교체 안 함 / 원곡 MV→원곡 다운로드: 교체함). 새 app 테스트는 이름을 요약에 적을 것(CI 목록 추가는 Opus 가 함).

제약: 배터리 우선(주기 폴링·타이머 금지, 이벤트 기반). 바꾼 함수의 모든 호출부와 타입을 다시 읽고 확인. 기존 코드의 의도(주석·설계)를 지울 때는 요약에 이유를 적을 것. .github/, keys, 서명 설정 수정 금지. 싱크·가사 계산 코드는 건드리지 말 것.

마지막에 10줄 이내로 요약: 수정 파일 / 핵심 변경 / 테스트 결과 / 미해결 문제.
