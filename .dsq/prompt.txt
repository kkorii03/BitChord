# UI/UX 애플뮤직 비교 감사 (2026-10-25, S24 실기기 ko-100 시험판 v48, 캡처: phone-out\audit\)

## A. 버그 (확실히 고쳐야 함)
1. 아티스트 페이지 맨 아래 정보 칩: "구독자 구독자명", "월간 청취자 월간명" — 숫자 대신 틀 문구가 그대로 나옴(문자열 포맷 오류). (art4)
2. 앨범·재생목록 페이지를 내리면 셔플/재생/추가 버튼이 상태표시줄·상단 버튼 뒤로 그대로 비침(상단 막대 배경 없음). 애플뮤직은 흐린 배경 + 가운데 제목이 생김. (alb2, crop_alb2)
3. 재생 화면 흐르는 제목이 왼쪽 끝에서 글자 중간이 뚝 잘림("ng (I'm So In Love)", "ı So In Love)"). 양 끝 페이드 없음. (crop_pl1, set0)
4. 재생 화면 가사 미리보기 줄: 영어 줄과 다음 한국어 줄이 같은 자리에 겹쳐 보이는 순간. (crop_pl1 "Eh" + 흐린 한글)
5. 홈 상단에 안드로이드 머티리얼식 회색 원형 새로고침 표시가 남아 있음. (home1)

## B. 번역 안 된 문구
6. 둘러보기: "Enka/kayokyoku", "Anime & soundtracks", "Seasonal", "Vocaloid & utaite"(→ 엔카/가요곡, 애니메이션 & 사운드트랙, 시즌, 보컬로이드 & 우타이테). "J-Rock"은 그대로 둬도 됨.
7. 보관함: "Podcasts" → "팟캐스트".

## C. 애플뮤직과 다른 표시(유튜브식)
8. 홈·검색·아티스트의 부제에 "조회수 23…", "구독자 423만명", "월간 시청자 6.19억명", "1723만회 재생". 애플뮤직은 "재생목록 · 큐레이터", "아티스트", "앨범 · 연도"만.
9. 홈에 "Shorts" 섹션(유튜브 전용).
10. 아티스트가 네모 사진으로 나옴(보관함 아티스트, 아티스트 페이지의 "팬이 좋아할 만한 다른 아티스트"). 애플뮤직은 항상 원형. 보관함 "에런 터베이트"는 아티스트 사진 대신 앨범 표지.
11. 재생 화면 앨범아트 위 기술 정보 2줄 상시 표시("Opus · 48.0 kHz · 138 kbps · 스테레오 / 자동 믹스 · 현재 노래: 분석 완료…"). 애플뮤직은 "무손실" 배지 하나. → 기본은 숨기고 눌렀을 때만.
12. 재생 화면 아래 가운데: 휴대폰|사람 두 칸 버튼 + 항상 "장재훈의 휴대폰" 표시. 애플뮤직은 AirPlay 아이콘 하나, 외부 기기일 때만 이름.

## D. 레이아웃·타이포·간격
13. 앨범 헤더: "Bruno Mars, 앨범, 2026년"이 제목급으로 크고 쉼표 나열 + 아래 "앨범 · 9곡 · 31분"으로 '앨범' 중복. 애플뮤직: 아티스트명(강조색) / "장르 · 연도"(작게). 곡 수·시간은 목록 끝에.
14. 앨범 버튼: 원형 셔플 + 큰 흰 재생 + 원형 추가. 애플뮤직: "▶ 재생", "셔플" 같은 크기 두 버튼(회색 배경).
15. 앨범 곡 목록 줄마다 "Bruno Mars"와 재생 시간 반복 → 줄이 높고 복잡. 애플뮤직 앨범은 번호 + 제목(+ 피처링만). 목록 끝 발매일·곡 수·저작권 없음, 빈 공간만.
16. 곡 메뉴(⋯): 아이콘 왼쪽·글자 오른쪽(안드로이드식), 맨 위가 "원래대로 되돌리기", "비디오로 전환". 애플뮤직: 글자 왼쪽·아이콘 오른쪽, 위에 보관함/재생목록/다음에 재생.
17. 설정: 아이콘 있는 줄·없는 줄이 섞여 글자 시작 위치가 들쭉날쭉("휴대폰 스피커에서는 끄기", "비디오 노래도 자동 믹스", "Wi-Fi에서만 다운로드"). 꺼진 토글이 카드 배경과 거의 같은 색. 줄 설명이 3~4줄로 김.
18. 둘러보기 타일: 왼쪽 단색 띠 + 오른쪽 사진의 반반 구조, 사진 없는 타일("록", "Seasonal"). 애플뮤직은 사진 꽉 채움 + 제목.
19. 스크롤 시 접힌 탭 버튼·미니플레이어·보관함 기록 버튼이 앨범 색(초록/빨강/분홍)으로 진하게 칠해짐. 애플뮤직은 무채색 유리.
20. 검색 결과: 일부 노래 줄만 재생 시간 표시(일관성 없음). 검색 첫 화면에 카테고리 없음(최근 검색만).
21. 보관함 메뉴 목록 아이콘이 흰 머티리얼 아이콘. 애플뮤직은 강조색(빨강) 아이콘. "캐시된 노래"는 개발 용어.
22. 좋아요 재생목록 표지가 유튜브식 엄지 아이콘.
