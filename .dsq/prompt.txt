[검토자 지적 — 전부 고칠 것]
- HIGH `scripts/smoke/run.sh:112-116` — `track-summary` is written for the outgoing track on a transition, so the final song (the Dance Monkey cover) has no successor and its summary is never logged; check 1 therefore never evaluates it. Fix: force one final track change (e.g. start a dummy seventh link or send NEXT) or wait for playback to end before dumping.
- MEDIUM `scripts/smoke/run.sh:68,116` — the only logcat dump is at the end; the default ring buffer can wrap during six 45s songs, dropping early `track-summary`/`play:` lines and making `play_count` unreliable. Fix: stream `adb logcat` to the file for the whole run, or raise the buffer and dump per song.
- MEDIUM `scripts/smoke/run.sh:32-36,116-117` — a missing APK falls back to an unverified installed package and a failed/empty logcat dump is ignored, while `smokecheck` treats an empty log as all-PASS. Fix: require the APK or `pm path`, verify the dump succeeded and is non-empty, and exit 2 otherwise.
- MEDIUM `scripts/smokecheck.py:249-262` — the audio-switch exemption matches only title, dropping the artist/id, so a different video with the same title is excused and an unreplaced MV can pass. Fix: correlate the failure to the summary's video id (or parse the `play:` line's id/title/artist) and add a same-title/different-artist test.
- LOW `scripts/smokecheck.py:164-166` — only `kept (none)` is accepted; a downloaded cover logs `kept (local file, none)` and still fails check 1. Fix: accept the local-file-none form too and test a downloaded cover.
- LOW `scripts/smoke/run.sh:88,105-108` — the 45s timer starts before VIEW/fallback detection, so a fallback-started song is listened to for only ~10s despite the comment claiming the same listening window. Fix: start the 45s wait after playback is detected.
