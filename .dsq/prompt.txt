작업: 재생 화면 아래 셔플 / 반복 / ∞(자동 재생) 세 버튼의 켜짐·꺼짐이 화면에서 구별되지 않는 버그 수정 (Apple Music 한국어판처럼). 기준 task/integrate.

폰에서 확인한 사실(S24, 10-26 21:50, 스크린샷으로 직접 비교):
- 반복 모드 '전체 반복(REPEAT_MODE_ALL)'일 때와 '꺼짐(REPEAT_MODE_OFF)'일 때 반복 아이콘이 완전히 똑같이 그려진다. '한 곡 반복'만 아이콘 대신 '1' 글자가 보인다.
- 그래서 사용자는 전체 반복이 켜진 줄 몰랐고, 전체 반복 중에는 자동 재생이 일부러 멈추므로(PlaybackService.loadAutoplayForCurrentTrack repeatAll 조건) 1곡짜리 대기열이 끝없이 반복됐다.
- ∞(자동 재생)·셔플도 켜짐/꺼짐 모양이 같아 보인다.
- 버튼 묶음은 MainActivity.kt 2885~2916줄(repeatMode, shuffleEnabled, autoplayEnabled, onCycleRepeat, onToggleAutoplay)을 받는 NowPlayingScreen 쪽 컴포저블. 실제 그리는 파일은 grep 으로 찾을 것(rg 없음, 전체 목록 출력 금지).

할 일:
1. 세 버튼 모두 켜짐 상태를 Apple Music 처럼 분명하게: 켜진 버튼은 밝은(흰색 계열, 불투명도 높은) 둥근 배경 + 어두운/배경색 아이콘, 꺼진 버튼은 지금처럼 반투명 배경 + 흰 아이콘. 색은 지금 화면의 동적 배경색(앨범 색)과 대비가 확실해야 함.
2. 반복: 꺼짐 = 반복 아이콘(꺼진 모양), 전체 반복 = 반복 아이콘(켜진 모양), 한 곡 반복 = 반복 아이콘에 작은 '1' 배지(켜진 모양). '1' 글자만 덩그러니 보이는 지금 모양을 바꿀 것.
3. 접근성: 각 버튼 contentDescription 을 상태 포함으로 — '반복: 끔' / '반복: 전체' / '반복: 한 곡', '셔플: 켬/끔', '자동 재생: 켬/끔' (합니다체·명사형, Apple Music 한국어판 용어). 지금은 이 버튼들이 접근성 트리에 아예 안 보인다(uiautomator 덤프에 없음).
4. 상태 → (켜짐 여부, 아이콘, 배지, 설명) 을 정하는 순수 함수 + 단위 테스트(REPEAT_MODE_OFF/ALL/ONE 각각, 셔플·자동 재생 켬/끔). 이 테스트는 지금 코드에서는 실패해야 한다(전체 반복과 꺼짐이 같은 모양이라는 버그를 증명).

제약: 기존 동작(누를 때 순서 OFF→ALL→ONE→OFF, 자동 재생 로직)은 바꾸지 말 것. 화면 배치·크기 유지. 배터리 우선(애니메이션 무한 반복 금지). .github/, keys, 서명 수정 금지.
