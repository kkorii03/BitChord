# 비디오 노래 자동 재생 (설계 — Opus, 10-26 사용자와 상의)

사용자 요청: 커버 영상(비디오 노래)을 듣다가 자동 재생이 공식곡으로 넘어가지 않고
비디오 노래로 계속 이어지게. 예) 오화요 댄스몽키 → 오화요 써클 → 리제 청록.

## 결정 사항
- 켜는 방식: **자동으로 켜짐 + 스위치로 끔**(사용자 결정). 재생 화면 대기열(다음 재생) 위에 '비디오 노래 이어 듣기' 스위치, 설정 > 재생에도 기본값.
- 같은 가수 비율: 같은 가수 1 : 다른 가수 2(Opus 추천, 사용자 이견 없음). 같은 가수 연속 최대 2곡.
- 공식곡: 섞지 않음. 후보가 바닥나면 그때만 기존 자동 재생으로.
- 시작 시점: 지금 진행 중인 검토·합치기(다운로드 굳음, 다음 곡 준비, 애플 2차, 의존성 고정)가 끝난 뒤. 다음 곡 준비(yb4)·다운로드 검증과 같은 재생 경로를 건드리므로 그 위에서 만든다.

## 동작
1. 모드 판단(순수 함수): 시드 곡이 비디오 노래 = YouTube 영상이고 채널이 '- Topic'·공식 아티스트 채널(OAC)이 아니며, 공식 MV(제목에 'Official'·'M/V'·'MV' + 아티스트 채널)가 아님. 커버·라이브·노래 영상.
2. 후보 재료: youtube.com 의 영상 믹스(list=RD<videoId>, 한국에서도 프록시 불필요) + 같은 채널의 다른 노래 영상(채널 업로드, 최근·인기) + 사용자 재생목록 두 개(PL02cgYzp6Oi4kOisQAh691u0phBtC4PVD, PL-ODED49YdZByxxHBLaIIOOePlhj8nWcc)에 있는 가수를 가중치로.
3. 걸러내기(순수 함수 + 테스트): 길이 90초~8분, 쇼츠 제외, 제목·설명에 노래 표시(커버, cover, 불러봤, 불러보았, live, 라이브, 노래, sing, 歌ってみた) 또는 음악 분류, 잡담·브이로그·리액션·하이라이트·클립 모음 제외, 최근 50곡 안에 들은 영상·같은 곡 다른 커버 연속 금지.
4. 노래 버전 교체 금지: 이 모드의 곡은 MV→노래 버전 교체(SongVersion)를 건너뛴다. 단 공식 MV 가 섞여 들어오면 기존 규칙대로.
5. 가사·싱크: CoverTitles(커버 제목 인식) + 곡 확인(Deepgram) 경로 그대로. 다음 곡 준비(yb4) 묶음도 그대로 적용.
6. 배터리: 후보는 대기열이 3곡 이하로 줄 때만 한 번 더 가져오기(이벤트), 폴링 없음.
7. 로그: 'video-radio: seed=<id> mode=<on|off> picked=<id> from=<mix|channel|playlist> same-singer-run=<n> dropped=<사유별 수>'.

## 반대 방향도 같은 무게로(사용자 강조 10-26): 일반곡 → 커버로 새지 않기
- 시드가 일반곡(노래 버전·공식곡)이면 '일반곡 모드': 자동 재생 후보에서 커버·노래방·피아노·Inst/MR·8비트·lofi 편곡·팬 클립·사용자 업로드 노래 영상을 뺀다(같은 편곡 판정 함수를 두 모드가 공유 — 다운로드 검증(download-health)·고음질 후보 판정과도 같은 함수).
- 지금 자동 재생(YouTube Music watch next/radio, musicOnly 표시)이 실제로 커버를 섞는지 로그 'queue: set … musicOnly=' 와 코드로 먼저 확인하고, 섞는 경로(라디오 이어 받기, 셔플 보충, 자동 재생 꼬리 추가)마다 필터를 건다.
- 일반곡 모드에서 커버가 0곡인지: ui-tour 에서 Dance Monkey(공식) 시작 자동 재생 10곡 기록, S24 30분 로그.
- 모드 판단은 '시드' 기준이고, 사용자가 직접 고른 곡은 어느 모드든 그대로 재생(필터는 자동으로 붙는 곡에만).

## 충돌 점검(구현 전 확인)
- 기존 자동 재생(YouTube Music watch next / radio), 셔플, 사용자가 직접 넣은 대기열(절대 덮어쓰지 않음, 자동 재생 꼬리에만 추가), 함께 듣기(파티 중에는 끔), 자동 믹스(그대로), 다운로드 곡(오프라인이면 다운로드된 비디오 노래만), 노래 버전 교체, MV 금지 원칙(공식 MV 는 노래 버전으로 — 기존 규칙 유지).

## 검증
- 순수 함수 테스트(모드 판단·걸러내기·비율) + CI.
- 에뮬레이터 ui-tour: 오화요 댄스몽키에서 시작해 자동 재생 10곡 제목 기록 → 공식곡 0, 같은 가수 연속 ≤2.
- S24: 30분 연속 재생, 로그 video-radio 줄 확인, 스위치 끄면 기존 자동 재생으로 돌아가는지.
