[자동 재생 시험 스크립트 — .github 는 수정 금지, scripts/smoke/ 아래에만]
목적: 에뮬레이터(GitHub 러너, API34)에서 앱을 설치해 실제로 곡을 재생시키고 logcat 을 scripts/smokecheck.py 로 판정한다. 기존 에뮬레이터 화면 시험 스크립트 .github/ui-tour/tour.sh 를 읽고 같은 방식(adb, 앱 패키지 이름, 로그인 없는 첫 실행 처리, 권한 허용, 언어)을 따른다.
 scripts/smoke/run.sh 를 만든다: 1) 설치된 디버그 APK 실행, 첫 화면 처리 2) 다음 YouTube 영상 id 를 차례로 'am start -a android.intent.action.VIEW -d https://music.youtube.com/watch?v=<id> -p <패키지>' 로 재생, 곡마다 45초 대기: -RJSbO8UZVY(Youngblood MV), QYh6mYIJG2Y(7 rings MV), ekzHIouo8Q4(When I Was Your Man MV), av5JD1dfj_c(Dancing With A Stranger MV), CnAmeh0-E-U(Sucker MV), US2I6tSRjcE(오화요 Dance Monkey 커버 — 커버라 그대로 재생돼야 함). VIEW 로 재생이 시작 안 되면 tour.sh 처럼 MEDIA_PLAY_FROM_SEARCH 대안. 3) logcat 을 shots/smoke-logcat.txt 로 저장 4) python3 scripts/smokecheck.py 로 판정, 결과 shots/smoke-report.md, 종료 코드 전달.
 또 scripts/smokecheck.py 의 1번(MV 재생) 판정을 고친다: video=y 라도 커버·노래 영상(제목에 MV 표식이 없고 'audio switch' 가 카탈로그 노래를 못 찾은 경우)은 PASS 로. 제목에 MV 표식이 있는데 song version 교체가 없으면 FAIL. 테스트 갱신.
 bash -n 으로 문법 확인, python 단위 테스트 실행. 마지막에 6줄 요약.
