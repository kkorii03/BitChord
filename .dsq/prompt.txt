작업: fix-mv-r4 재작업 (Opus 검토 불합격). 기준 = 이 브랜치(cloud/fix-mv-r4)의 결과.

치명 결함: DownloadedMvPolicy.mvSoundSuspectDeltaMs 의 knownMv = storedIsVideo == true || storedTypeUnknown || ... 때문에
(1) 다운로드한 커버·라이브·노래 영상(isVideo=true, 자기 스트림) 전부가 'MV 소리 의심'이 된다.
(2) typeUnknown 인 정상 노래 다운로드도 전부 의심이 된다.
의심 목록은 Downloads.kt 854줄 MvSoundRedownload.scheduleIfEnabled 로 자동 재다운로드된다 → 사용자가 받아 둔 커버 영상이 원곡으로 자동 교체된다(사용자 원칙 위반: 커버는 커버 그대로).

할 일:
A. 의심 판정 규칙 수정: '공식 MV 의 소리'일 때만 의심. 조건 = 커버가 아님(CatalogSongMapper.isCover/CoverTitles.isCover) AND [ MV 제목 표시(hasMvTitleMarker) OR (soundSourceVideoId != null && soundSourceVideoId != rowVideoId && 그 source 가 MV 로 기록됨) OR 기존 legacy 길이 규칙 ]. isVideo=true 단독, typeUnknown 단독으로는 의심 금지.
B. MvSoundRedownload 가 재다운로드 직전에도 커버 판정을 한 번 더 해서 커버면 건너뛰게(이중 안전장치).
C. keepsStoredUploadType / isRecordedSongVersion 변경은 유지 가능(검토 OK).
D. 재현 테스트(실제 값, shared com.music.bitchord.data.net):
   의심 아님: 행 'ダンスホール - Dance Hall' / 'Mrs. GREEN APPLE · 오화요 커버', isVideo=true, source=자기 id
             행 '야화' / '안예은 · 오화요 커버', isVideo=true
             행 'Youngblood' / '5 Seconds of Summer', isVideo=false, typeUnknown=true, 파일 길이=카탈로그 길이
   의심: 행 'Youngblood (Official Video)' / '5 Seconds of Summer', isVideo=true (MV 표시)
         행 'That's What I Like' / 'Bruno Mars', 파일 210.7s, 카탈로그 206.7s, legacy (기존 길이 규칙 그대로 판정 — 기존 테스트 값 유지)
   그리고 '고치기 전 실패 → 고친 뒤 통과'를 요약에 명시.
