측정 항목(로그 줄 형식은 앱 코드에서 grep 으로 실제 형식을 확인하고 맞출 것 — 아래는 실제 로그 예):
D1 다음 곡 준비: 'next-prep: <제목> version=<id> lyrics=<제공처|none> hq=<id|none> sync=<applied|skipped(...)> mix=<ready|none> in <ms>ms' → 단계별 성공률, lyrics!=none 인데 sync=skipped 비율, 시간 평균·최대. 기준: 가사 있는 곡 sync applied ≥80%.
D2 무손실: 'hq-verify: ... -> accepted' 또는 'upgrade ahead: '<제목>' ready at FLAC' 뒤 같은 곡이 실제로 FLAC 재생됐는지 — 크로스페이드·재생 줄의 '[player-a:flac]'/'[player-b:opus]' 표기, 'DECODE ... flac', 'hq-swap: <id> done', 'already playing audio/flac from cache' 로 판정. 'kept for next play; no mid-song swap' 와 'manual upgrade unnecessary' 수 따로. 기준 ≥90%.
D3 자동 재생: 'autoplay: +radio N +similar N +fav N (...)' 를 성공(합 >0), 'autoplay: dropped N cover/karaoke rows' 뒤 같은 초 안에 +radio 줄이 없으면 0곡 보충. 'play: -> ... reason=REPEAT' 인데 직전 'mode: repeat=off' 상태면 원치 않는 반복. 'video-radio: seed=.. mode=.. picked=N from=.. fallback=..' 도 집계(D4: mode=video 일 때 picked 와 from 분포).
D5 노래 버전: 'track-summary: <id> '<제목>' video=<y|n> source=... resolve=... firstAudio=<ms|-> played=<s> lyrics=<..> sync=<none|measured|ai|refine..> shift=.. match=.. manualOffset=.. ended=<natural|skipped|error>' 에서 video=y 비율(제목에 커버/cover/clip 등 비디오 노래 표시가 있는 곡은 따로), 'song version: <id> -> <id> via ..' vs 'kept (none)'·'kept (timeout)'.
D6 가사·싱크: track-summary 의 lyrics!=none 비율, lyrics!=none 중 sync!=none 비율.
D7 자동 믹스: 'crossfade: start' / 'crossfade: skipped ... reason=' / 'crossfade: abort' / 'crossfade: end ... overlap=' 집계.
D8 재생 시작: firstAudio 분포(중앙값, 3초 초과 비율), ended=error 수, 'failed to start after N attempts' 와 그 곡 'play:' 시각부터 다음 'play:' 까지 시간.
D9 다운로드: 'download failed for <id>', 'hq-library: <id> did not land' (같은 id 반복 수), 'could not start the download service'.
D10 백그라운드: 'lifecycle: process start' 뒤 10초 안에 'lifecycle: foreground' 가 없는 시작 수, 그 구간의 'InnerTubeX warmed'·네트워크 줄 수.
D11 품질 표시: 'manual upgrade unnecessary' 또는 되돌리기 관련 줄 시각에 실제 재생 형식이 opus 인 경우.
