할 일:
1. 자동(사용자가 누르지 않은) 고음질 다운로드는 호스트당 한 번에 1개만(재생 중 곡의 스트림·검사와도 겹치지 않게 같은 호스트 잠금 공유 가능하면 공유). 재생 중에는 시작하지 않거나 재생 곡 버퍼가 끝난 뒤(이벤트 기반).
2. 429/503: Retry-After 를 지키고 없으면 지수 대기(1분→2분→4분, 최대 30분), 같은 세션 안에서 WorkManager 백오프로 재시도. 즉시 '실패'로 확정하지 말 것. stream reset 도 같은 일시 오류로 취급.
3. 자동 작업의 실패는 빨간 '!'(사용자 오류 알림)로 올리지 말 것 — 사용자가 직접 요청한 다운로드 실패만 표시. 자동 작업은 다운로드 화면 안에서 '대기 중(서버 혼잡)' 정도로만.
4. 한 번에 시작하는 자동 작업 수 상한(예: 큐에서 1개씩 순차).
재현 테스트(고치기 전 실패 → 후 통과): 동시 출발 방지(같은 호스트 2개 요청 시 순차), 429 → 재시도 예약(실패 아님), 자동 작업 실패가 사용자 알림 카운트에 안 들어감 — 순수 함수로.
