BitChord 안드로이드 앱(Kotlin). 검색은 grep/git grep, 큰 목록 출력 금지(끝까지 작업). 현재 브랜치 = task/fix-1030(여러 검토 결과를 합친 통합판).
할 일: 'git fetch origin cloud/leftovers-data-settings-1031-r2' 후 'git merge --no-commit --no-ff FETCH_HEAD' 로 그 브랜치를 합치고 충돌을 해결. 충돌 파일마다 양쪽 변경의 의도를 모두 살릴 것(양쪽 커밋 메시지와 diff 를 읽고, 한쪽을 통째로 버리지 말 것). 해결 뒤 .github/ .dsq/ 는 현재 브랜치 것으로 되돌림. 그 브랜치가 추가한 테스트가 통과해야 함. 이번 작업은 합치기만 — 새 기능·리팩터링 금지. 합치기 결과를 커밋하지 말고 작업 트리에 둘 것(워크플로가 커밋함).
마지막에 10줄 이내로 요약: 충돌 파일 / 각 파일에서 양쪽 의도를 어떻게 합쳤는지 / 테스트 결과.

참고: 얕은 체크아웃이면 먼저 'git fetch --deepen=500 origin'. 언어별 strings.xml 충돌은 양쪽에 새로 추가된 <string> 을 모두 남기되 같은 name 은 한 번만(현재 브랜치 값 우선). 다른 언어 파일에 영어 문장을 새로 넣지 말 것 — 번역이 없으면 그 언어 파일에는 넣지 않음(기본 values 로 대체됨).
