[시험용 훅 — dev 디버그 빌드에만, 사용자 배포판(prod release)에는 절대 포함되지 않게]
에뮬레이터 자동 시험에서 사용자의 고음질 소스 설정(.bitchord-settings, SettingsTransfer 형식, proxy 항목은 없음)을 앱에 넣어야 한다. 앱의 '설정 가져오기'는 미리보기에서 '적용'을 눌러야 한다.
 1) dev 디버그 빌드에서만 등록되는 BroadcastReceiver(app/src/devDebug 또는 debug 소스셋의 AndroidManifest 에만): 'adb shell am broadcast -a com.music.bitchord.debug.IMPORT_SETTINGS --es path /data/local/tmp/smoke.bitchord-settings -n <패키지>/<리시버 클래스>' → 파일을 읽어 SettingsTransfer 의 검증·적용 경로로 바로 적용(미리보기 생략), 로그 'debug-import: applied=<n> skipped=<n> sources=<n>'. 디버그 앱은 /data/local/tmp 를 직접 못 읽을 수 있으니, 리시버가 못 읽으면 'run-as <패키지> cp' 로 앱 캐시에 복사한 경로도 받게 하고 scripts/smoke/run.sh 에 그 방식을 쓴다.
 2) prod release 병합 매니페스트에 리시버가 없음을 ./gradlew :app:processProdReleaseMainManifest(또는 해당 태스크) 결과 grep 으로 확인해 요약에 결과.
 3) scripts/smoke/run.sh 가 있으면(다른 작업이 만드는 중일 수 있음) 시작 부분에 '환경변수 SMOKE_SETTINGS_FILE 이 있으면 push 하고 import 방송, 로그에서 debug-import 줄 확인' 단계를 넣고, 없으면 scripts/smoke/import-settings.sh 로 따로 만든다. 고음질 확인을 위해 재생 목록에 노래 버전 곡도 3개 추가(Golden TuzfXgUpboA, Houdini cCfPDrRQp9k, Murder On The Dancefloor RCtTDJgxPDA, 곡마다 90초 — 고음질 검증이 끝날 시간).
 컴파일(:app:compileDevDebugKotlin, :app:compileProdReleaseKotlin) 직접 실행. 마지막에 6줄 요약.
